# API reference — d1

> Exact REST endpoints for **d1**, sliced from the Cloudflare OpenAPI spec (api.cloudflare.com v4). 12 operations. Base: `https://api.cloudflare.com/client/v4`.

> Body fields below are the **top-level required** ones only — not optional fields, nested
> shapes, enums or responses. Added by scripts/slice-bodies; verify shapes against the live docs.

> ⚠️ Verify shapes/params against the live API docs before relying on them — specs drift.

- `GET /accounts/{account_id}/d1/database` — List D1 Databases  · required: account_id
- `POST /accounts/{account_id}/d1/database` — Create D1 Database  · required: account_id  · body: name:string
- `GET /accounts/{account_id}/d1/database/{database_id}` — Get D1 Database  · required: account_id, database_id
- `PUT /accounts/{account_id}/d1/database/{database_id}` — Update D1 Database  · required: account_id, database_id  · body: read_replication:object
- `PATCH /accounts/{account_id}/d1/database/{database_id}` — Update D1 Database partially  · required: account_id, database_id  · body: (no required fields)
- `DELETE /accounts/{account_id}/d1/database/{database_id}` — Delete D1 Database  · required: account_id, database_id
- `POST /accounts/{account_id}/d1/database/{database_id}/export` — Export D1 Database as SQL  · required: account_id, database_id  · body: output_format:string
- `POST /accounts/{account_id}/d1/database/{database_id}/import` — Import SQL into your D1 Database  · required: account_id, database_id  · body: action:string, etag:string
- `POST /accounts/{account_id}/d1/database/{database_id}/query` — Query D1 Database  · required: account_id, database_id  · body: sql:string
- `POST /accounts/{account_id}/d1/database/{database_id}/raw` — Raw D1 Database query  · required: account_id, database_id  · body: sql:string
- `GET /accounts/{account_id}/d1/database/{database_id}/time_travel/bookmark` — Get D1 database bookmark  · required: account_id, database_id
- `POST /accounts/{account_id}/d1/database/{database_id}/time_travel/restore` — Restore D1 Database to a bookmark or point in time  · required: account_id, database_id
