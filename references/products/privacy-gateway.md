# Privacy Gateway → renamed Cloudflare OHTTP Relay

> Privacy Gateway is now **Cloudflare OHTTP Relay** (managed Oblivious HTTP relay). This stub exists for readers arriving with old links. **Use `products/ohttp-relay.md`.**

- Relay URL convention is unchanged: `https://privacy-relay.cloudflare.com/<GATEWAY_SERVER_NAME>`.
- Relay-side logs are now called "Cloudflare OHTTP Relay Logs" (~124 days retention).
- Docs: `https://developers.cloudflare.com/ohttp-relay/`.
