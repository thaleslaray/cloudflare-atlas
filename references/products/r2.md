# R2 — object storage (S3-compatible, zero egress fees)

> Store large amounts of unstructured data (files, images, backups, video) with an S3-compatible
> API and **no egress charges**. The Cloudflare-native answer for object/file storage.

## Contents

## When to use
- Object/file storage: user uploads, images, video, backups, data lakes, static assets.
- You want **zero egress fees** (the killer feature vs S3) — serving lots of data out is free.
- Pairs with: Workers (compute), Images (transform), Stream (video), Basin Pipelines/Basin SQL (analytics).
- **Not** for: relational data (→ d1/hyperdrive), key-value (→ kv), search vectors (→ vectorize).

## Binding & config (`wrangler.jsonc`)
```jsonc
{
  "r2_buckets": [
    { "binding": "MY_BUCKET", "bucket_name": "my-bucket" }
  ]
}
```
Access in Worker: `env.MY_BUCKET.get(key)` / `.put(key, data)` / `.delete(key)` / `.list(opts)`.
Also: S3-compatible REST API (use existing S3 SDKs) and a public-bucket / custom-domain option.

## Access patterns
- **Workers binding** — `env.MY_BUCKET.*` from a Worker (lowest latency, no keys).
- **S3 API** — point any S3 SDK at the R2 endpoint with an R2 access key (for existing tooling).
- **Public bucket / custom domain** — serve objects directly over HTTP(S).
- Stream large/unknown-size bodies — R2 object bodies are streams; do not buffer with `.text()`
  /`.arrayBuffer()` unless the object is known-small.

## Gotchas
- **List truncation:** loop on `listed.truncated` + `cursor`, NOT on `objects.length` — `include`
  with metadata may return fewer objects per page.
- **ETag:** use `object.httpEtag` (quoted) in headers, not `object.etag` (unquoted).
- **One checksum per PUT:** `put(key, data, { sha256 })` — passing md5 AND sha256 errors.
- **Multipart** for very large uploads: max **10,000 parts**, and any single upload/part request is
  capped at **5 GiB** (4.995 GiB) — a >5 GiB object *must* be multipart.
- Buffering R2 bodies on large objects → memory exhaustion. Stream instead.
- **Data Access Logs** (GA, 2026-09) — per-request object logs (Get/Head/Put/Copy/List/multipart/Delete,
  via S3, API, Workers binding with script name, or `Public`), viewed in **Workers Observability** (`r2`
  dataset). **Not an audit trail:** only status `< 400`, best-effort and may drop events, not retroactive,
  and unavailable on **jurisdiction** buckets. Config changes are Audit Logs, not these.
- **Bandwidth by Cloudflare location** (2026-10-09) — R2 overview metrics chart: top 5 serving locations by
  default (pick up to 6), filter by bucket and download vs upload → `developers.cloudflare.com/r2/platform/metrics-analytics/`.

## Pricing & limits
> ⚠️ Pricing changes — verify on the live page (`developers.cloudflare.com/r2/pricing/`) before quoting.

**Cost drivers** (verified 2026-08-25; page marked "Last updated Aug 7, 2026"):

Standard storage:
- Storage: **$0.015 / GB-month**
- Class A ops (writes/mutations: PUT, LIST...): **$4.50 / million**
- Class B ops (reads: GET, HEAD...): **$0.36 / million**
- **Egress: FREE** (the differentiator)
- Free tier (monthly): 10 GB-month storage + 1M Class A + 10M Class B — **Standard only**, does not
  para Infrequent Access.
- **Infrequent Access** storage class: $0.01/GB-month, Class A $9.00/M, Class B $0.90/M, mais
  **data retrieval $0.01/GB** e mínimo de **30 dias** de cobrança por objeto. Egress segue free.
- `DeleteObject`, `DeleteBucket` and `AbortMultipartUpload` are **free** operations (neither A nor B).

**Key limits:** object size **5 TiB** · objects/bucket **unlimited** · storage/bucket **unlimited**
· buckets/account 1,000,000 · key length 1,024 bytes · object metadata 8,192 bytes · bucket
management ops 50/s **per bucket** · custom domains/bucket 100 · concurrent writes to the same
key 1/s (above that → HTTP 429) · Cloudflare REST API **1,200** req / 5 min per account. Verify on
`developers.cloudflare.com/r2/platform/limits/`.
